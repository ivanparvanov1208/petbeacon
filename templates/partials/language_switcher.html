{% load i18n %} {% comment %} Language switcher for the desktop header. Hidden below the `md` breakpoint, where the mobile drawer carries the segmented control instead — two controls for the same job would just be duplicate tab stops. The POST form lives inside the (absolutely positioned) dropdown rather than wrapping the trigger, so the trigger stays a plain flex child of the header and no stray box appears in the bar. `next` holds the current path, which Django's set_language view rewrites to the same page in the chosen language (it understands the i18n_patterns prefix). Submitting a form rather than following an href means the switcher still works without JavaScript. Language names are shown in their own language (Български, English) on purpose: a reader hunting for their language scans for the endonym, not for an English gloss. That is why these come from settings.LANGUAGES and are not translated strings. {% endcomment %}
